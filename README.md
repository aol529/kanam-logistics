# Kanam Logistics Limited

Company website and CMS. Static HTML/CSS/JS backed by Supabase.

**Website**: Home, About, Services, Pishori Rice, Projects, News and Contact, with the order / quote form and a WhatsApp button. Live at https://aol529.github.io/kanam-logistics/.

**Kanam CMS** (`/portal/`): staff sign in and manage the whole site.

| Section | What it does |
|---|---|
| Dashboard | New inquiries, stock, news drafts, details still to fill in, recent changes |
| Inquiries | Orders and quote requests from the site: status, staff notes, call / WhatsApp, download as CSV, send a rice order to the ledger |
| Rice ledger | The trading ledger: per batch, purchase, costs, selling trips and pricing (break-even, target price per bag), a sales log you type straight into, and progress against costs and the profit target. Download as Excel. Admin and sales only |
| Pages | Every headline, paragraph, list item and button on every page, plus each page's Google title and description |
| News | Posts with cover photo, simple formatting, draft / published / scheduled |
| Media library | Upload photos once, reuse them anywhere; alt text and captions |
| Products, Projects | Rice bags and prices, stock; road works, supplies and rice projects |
| Testimonials, FAQs, Team | Shown on Home, Contact and About (testimonials and team stay hidden until there is one) |
| Company details | Phone, WhatsApp, email, KRA PIN, registration, About text... used across the site |
| Company profile | Tender documents (incorporation, CR12, KRA PIN & TCC, directors, trade license, NCA, power of attorney, AGPO, litigation & affidavit, bank statement, audited accounts, past experience): upload, preview, expiry warnings, download all as one ZIP. **Private, admins only** |
| Staff | Add staff and set their role |
| Activity log | Every change: who, when, and what it was before |

Roles: **admin** (everything), **editor** (website content), **sales** (inquiries, rice ledger, products, media).

## Placeholders

Anything in `[square brackets]` is a placeholder and shows **highlighted in yellow** on the site, and the Dashboard lists what is left. Replace them in Company details. Photo spaces are the striped boxes.

## Setup

1. Create a Supabase project and put its URL and publishable key in `js/config.js`.
2. In its SQL editor, run `sql/01-schema.sql`, then `sql/02-cms.sql`, then `sql/03-profile.sql`, then `sql/04-ledger.sql`.
3. Authentication → Users → **Add user** (your email and a password, tick Auto Confirm). Then in the SQL editor:
   `insert into public.staff (user_id, email, name, role) select id, email, 'Your name', 'admin' from auth.users where email = 'you@example.com';`
   (Later staff are added from the portal's Staff page.)
4. Authentication → Sign In / Providers: turn **off** "Allow new users to sign up".
5. `npm start`, then open http://localhost:3002 (CMS: http://localhost:3002/portal/).

Pushing to `main` publishes to GitHub Pages (`.github/workflows/pages.yml`).

## Editing the pages' layout

The HTML pages are generated by `tools/pages.py` (`pip install beautifulsoup4`, then `python3 tools/pages.py`). It tags each piece of text with a `data-c` key (page.section.element) that the CMS's Pages section edits. Keep each section's elements in the same order, or text saved in the CMS may move to a different element.
